    使用方法 · 获取 Cookie

    ← 返回登录

    必须使用 Chrome 浏览器（不要用 Edge）。按下面步骤复制后，粘贴到本机客户端 Cookie 文本框（支持整段 cURL，程序会自动抽出 Cookie）。

    1. 随便打开一个淘宝/天猫产品页链接
    2. 按 F12 打开开发者模式（右侧或下方出现开发者面板）
    3. 切到 Network（网络），点选筛选 Doc，再按 F5 刷新页面
    4. 在列表里找到 item.htm 那一行 → 右键 → Copy → Copy as cURL (cmd)（按图中箭头操作）
    5. 回到本机客户端，粘贴到 Cookie(可选) 文本框

    后台设置

    可配置参数来自 config.ini。密钥类用服务器 config.ini.local。
